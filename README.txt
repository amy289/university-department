UNIVERSITY COMPUTER SCIENCE DEPARTMENT WEBSITE
================================================

HOW TO USE
1. Extract the department folder.
2. Open VS Code.
3. Choose File > Open Folder and select the extracted department folder.
4. Open index.html with Live Server (or open it in a browser).
5. All eight pages share assets/css/style.css.
6. Images are local SVG assets in assets/images.
7. The contact page includes a map placeholder and a video element.
8. The contact form is a front-end demonstration only; it does not send email without a backend.

FILES
index.html, about.html, programs.html, faculty.html, courses.html,
admissions.html, news.html, contact.html
assets/css/style.css
assets/images/cs-mark.svg
assets/images/department-building.svg
assets/images/campus.svg
assets/department-intro.mp4 (if generated successfully)

VALIDATION
Run each HTML file separately through https://validator.w3.org/nu/
using the Text input option. This project uses one doctype and one main
element per page. The map is intentionally a placeholder as requested
by the lab scenario.
